## Deployment Instructions

### Local Preview
Simply open `index.html` in any browser, or run:
```bash
npx serve .
# or
python3 -m http.server 8080
```

### Deploy to Vercel
```bash
# From within the Projects/cerebral-veda directory:
vercel
# Or push to GitHub and connect repository in Vercel dashboard.
```
